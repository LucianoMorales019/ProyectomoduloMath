# Módulo Propio de Matemáticas (Unidad 6)

Este proyecto forma parte de los ejercicios prácticos de la **Unidad 6** de la materia Programación 1.
# Estructura:
`ModuloMath.py`: Es un módulo personalizado que contiene funciones matemáticas desarrolladas desde cero (`es_par`, `factorial`, `promedio`, `area_circulo`).
`Principal.py`: Es el script principal que importa el módulo `ModuloMath` y ejecuta cada una de sus funciones para mostrar los resultados en pantalla.
# Funcionamiento:
Clonar o descargar el repositorio 
luego ejecutar `Principal.py`
